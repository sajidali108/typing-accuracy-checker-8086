# Typing Accuracy Checker in 8086 Assembly

## Project Description
This project checks typing accuracy by comparing user input with predefined sentence and calculating mistakes.

## Tools Used
- NASM
- DOSBox
- AFD Debugger

## How to Run

mount c c:\asm
c:
nasm typing.asm -o typing.com
typing

## Features
- Dynamic sentence comparison
- Mistake counting
- Accuracy result
- Debugging support
